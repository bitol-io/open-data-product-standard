# Available third-party solutions & support

## Software vendors & package

Vendors who natively support ODPS (Open Data Product Standard).

A non-exhaustive, alphabetical list of organizations offering solutions natively compatible with ODPS, such as data catalogs, data marketplaces, provisioning tools, and more.

* [Databricks Ontos](https://marketplace.databricks.com/details/8c582cfa-4c6b-4fdc-93a2-f63b35d93906/Databricks_Ontos) - Governance and metadata management application using ODCS and ODPS as the core standards for data contracts and data products
* [Entropy Data](https://www.entropy-data.com) - Data Product Marketplace built on Data Contracts. Allows contract-first development of data products.
* [FLUID Forge](https://github.com/Agenticstiger/forge-cli) - Open-source Python CLI for authoring, planning, and applying data products. Bidirectional ODPS v1.0.0 import/export with schema validation and round-trip checks, per-port ODCS v3.1.0 contract linking, and native cloud apply for AWS Glue, BigQuery, and Snowflake.

If you spot a solution supporting the Open Data Product Standard, make a pull request!
