# Open Data Product Standard

## Executive Summary

This document describes the keys and values expected in a YAML data product, per the **Open Data Product Standard** (ODPS). The ODPS YAML file serves as the primary configuration and documentation for data products within your organization. The standard is divided into multiple sections, each with its own page: each section starts with at least an example, followed by the definition of each field/key.

For more details, see the sections below:

1. [Fundamentals](./fundamentals.md)
2. [Product Information](./product-information.md)
3. [Context (AI and semantic guidance)](./context.md)
4. [Management Ports](./management-ports.md)
5. [Support and Communication Channels](./support-communication-channels.md)
6. [Team](./team.md)
7. [Custom & Other Properties](./custom-other-properties.md)
8. [Authoritative Definitions](./authoritative-definitions.md)

## Notes

* The sections above contain example values. We carefully reviewed the consistency of those values, but we cannot guarantee that there are no errors. If you spot one, please raise an [issue](https://github.com/bitol-io/open-data-product-standard/issues).
* The data product should be **platform agnostic**. If you think this is not the case, please raise an [issue](https://github.com/bitol-io/open-data-product-standard/issues).
* The provided JSON schemas are companions to the standards (ODCS or ODPS), it means that they do not define the standards and may include bugs. In case of conflict between the standard and the JSON Schema, the standard takes precedence.
